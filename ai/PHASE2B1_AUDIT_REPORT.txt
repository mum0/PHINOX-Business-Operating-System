5. ADMIN/CEO LIMIT ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

5.1 Client-Side Check (Frontend)
────────────────────────────────
  var adminCount = 0, ceoCount = 0;
  _memberCache.forEach(function(m) {
    var r = String(m.role || m[3] || '').trim();
    if (r === 'Admin') adminCount++;
    if (r === 'CEO') ceoCount++;
  });
  if (data.role === 'Admin' && adminCount >= 1) { showToast('Only one Admin is allowed', 'error'); return; }
  if (data.role === 'CEO' && ceoCount >= 1) { showToast('Only one CEO is allowed', 'error'); return; }

5.2 Server-Side Check (Patched)
───────────────────────────────
  _checkAdminCEOLimit(data.role);

  function _checkAdminCEOLimit(role, excludeId) {
    role = String(role || '').trim();
    if (role !== 'Admin' && role !== 'CEO') return;
    var all = Members.getMembers();
    for (var i = 0; i < all.length; i++) {
      var m = all[i];
      var mRole = String(m[2] || '').trim();
      if (excludeId && m[0] === excludeId) continue;
      if (role === 'Admin' && mRole === 'Admin') {
        throw new Error('Only one Admin is allowed. An Admin already exists.');
      }
      if (role === 'CEO' && mRole === 'CEO') {
        throw new Error('Only one CEO is allowed. A CEO already exists.');
      }
    }
  }

5.3 Analysis
────────────
  • Client-side: Prevents unnecessary server call ✅
  • Server-side: Enforces even if client bypassed ✅
  • Both use same logic ✅
  • Race condition: Two simultaneous requests could bypass ⚠️ LOW RISK

VERDICT: ✅ ADMIN/CEO LIMIT IS CORRECT

10. REMAINING WARNINGS
═══════════════════════════════════════════════════════════════════════════════

1. ⚠️ RACE CONDITION — Admin/CEO Creation
   Two simultaneous requests could create two Admins/CEOs.
   Severity: LOW
   Mitigation: Server-side check catches most cases.

2. ⚠️ GUEST PERMISSIONS — Depend on Permissions Service
   If Permissions.getUserPermissions() returns unexpected values,
   Guest may get more/less permissions than intended.
   Severity: LOW
   Mitigation: Fallback to ['dashboard:read'] is safe.

3. ⚠️ MEMBER CACHE — Frontend uses _memberCache for Admin/CEO count
   If cache is stale, client-side check may be wrong.
   Severity: LOW
   Mitigation: Server-side check is authoritative.
