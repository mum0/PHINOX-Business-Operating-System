2. ACTUAL FINANCE SCHEMA (from 39_FinanceSchema.js)
═══════════════════════════════════════════════════════════════════════════════

2.1 LEDGER SCHEMA
─────────────────
Sheet: 'Ledger'
Headers (8 columns):
  A: id           — Entry ID
  B: date         — Transaction date (ISO format)
  C: type         — LEDGER_TYPE enum: REVENUE, COGS, EXPENSE, CASH_IN, CASH_OUT, REFUND, ADJUSTMENT
  D: amount       — Numeric (positive for inflow, negative for outflow)
  E: account      — Account name (Cash, Bank, etc.)
  F: referenceId  — Reference to Order/Sale/Expense ID
  G: description  — Text description
  H: status       — STATUS enum: POSTED, PENDING, REVERSED

2.2 EXPENSE SCHEMA
──────────────────
Sheet: 'Expenses'
Headers (10+ columns):
  A: id           — Expense ID (EXP- prefix)
  B: title        — Expense title
  C: category     — EXPENSE_CATEGORY enum
  D: amount       — Numeric amount
  E: status       — EXPENSE_STATUS enum: DRAFT, PENDING, APPROVED, REJECTED, POSTED
  F: submittedBy  — User email
  G: approvedBy   — Approver email
  H: rejectionReason — Text
  I: postedAt     — Date posted
  J: createdAt    — Creation date

VERDICT: SCHEMA MISMATCH — Type values are case-sensitive and format differs.

4. KPISERVICE FINDINGS (from 46_KpiService.js)
═══════════════════════════════════════════════════════════════════════════════

4.1 KPISERVICE ARCHITECTURE
───────────────────────────
KpiService is a COMPREHENSIVE KPI engine with:
  • 81 KPI definitions (DEFINITIONS object)
  • 8 categories: FINANCE, SALES, INVENTORY, OPERATIONS, MARKETING, SOCIAL_MEDIA, PERFORMANCE, CUSTOMER
  • Period support: DAILY, WEEKLY, MONTHLY, QUARTERLY, YEARLY
  • Idempotency: calculateKpi upserts, doesn't duplicate
  • Zero-division protection for 35+ KPIs
  • Dashboard: getDashboardKpis() returns all 81 KPIs

4.2 METHODS
───────────
  • calculateKpi(kpiId, period, refDate) — calculates single KPI
  • calculateAll(period, refDate) — calculates all 81 KPIs
  • calculateCategory(category, period, refDate) — calculates category
  • getDashboardKpis() — returns dashboard object
  • getKpiHistory(kpiId, limit) — returns history array

4.3 FINDING
───────────
The original UI_Server.js has uiGetDashboardKpis() which calls KpiService.
The patched uiGetKPIs was added as a SEPARATE, SIMPLIFIED function that:
  • Only returns 4 KPIs (revenue, expenses, profit, orders)
  • Bypasses KpiService entirely
  • Reads from sheet directly
  • Has no period filtering

This is ARCHITECTURALLY INCORRECT.
The correct approach is to use KpiService.calculateAll() or KpiService.getDashboardKpis().
